## 📱 테스트 화면 구성

### 화면 요소
1. **제목**: "RN Turbo Image Picker Test"
2. **이미지 미리보기**: 선택한 이미지 표시
3. **결과 텍스트**: 선택 상태 표시
4. **단일 이미지 선택 버튼**: 📷 단일 이미지 선택
5. **여러 이미지 선택 버튼**: 📸 여러 이미지 선택 (최대 10개)
6. **로그 영역**: 모든 작업 로그 실시간 표시

## 🧪 테스트 방법

### 1. 단일 이미지 선택 테스트
1. **"📷 단일 이미지 선택"** 버튼 클릭
2. 권한 요청 시 **허용** 클릭
3. 갤러리에서 이미지 선택
4. 선택한 이미지가 화면에 표시됨
5. 결과 텍스트에 "✅ Selected 1 image(s)" 표시
6. 로그 영역에 전체 과정 기록

### 2. 여러 이미지 선택 테스트
1. **"📸 여러 이미지 선택 (최대 10개)"** 버튼 클릭
2. 권한 요청 시 **허용** 클릭
3. 갤러리에서 여러 이미지 선택 (최대 10개)
4. 첫 번째 이미지가 화면에 표시됨
5. 결과 텍스트에 "✅ Selected X image(s)" 표시
6. 다이얼로그에 모든 이미지 URI 표시

### 3. 에러 시나리오 테스트
- 권한 거부: 버튼 클릭 → 권한 거부 → 에러 메시지 표시
- 이미지 선택 취소: 갤러리에서 뒤로 가기 → "Image picker cancelled" 표시
- 로그에서 전체 과정 확인

## 🔍 로그 확인

### 실시간 로그
- 화면 하단의 로그 영역에서 모든 작업 확인
- 각 작업의 타임스탬프 표시
- 에러 발생 시 상세 정보 표시

### Logcat 로그
Android Studio의 Logcat에서 더 자세한 로그 확인:
```
adb logcat | grep MainActivity
```

## 🐛 문제 해결

### 크래시 발생 시
1. 로그 영역에서 오류 메시지 확인
2. Logcat에서 상세 로그 확인
3. 에러 메시지를 기반으로 문제 진단

### 이미지가 표시되지 않음
- 권한이 허용되었는지 확인
- 로그에서 URI 확인
- 이미지 경로가 유효한지 확인

### 버튼이 동작하지 않음
- 로그 영역 확인
- 권한 상태 확인
- 에러 메시지 확인

## 💡 디버깅 팁
